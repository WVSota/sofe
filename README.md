# sunabaco sofe — 勤怠・シフト管理システム

---

## 起動方法

### 必要なもの
- **Node.js** (v16以上) → https://nodejs.org からインストール

### 手順

```
# 初回のみ
npm install

# 起動
node server.js
```

ブラウザで `http://localhost:3000` を開く。

> **ポート3000が使用中のエラーが出たとき**
> ```
> # 使用中のプロセスを終了
> netstat -ano | findstr :3000
> taskkill /PID <表示されたPID> /F
> ```

## 打刻（打刻タブ）

### ボタンの使い方

| ボタン | タイミング |
|--------|-----------|
| 出勤   | 出勤時にタップ |
| 退勤   | 退勤時にタップ |
| 休憩開始 | 休憩に入るときにタップ（出勤後のみ押せる）|
| 休憩終了 | 休憩から戻ったときにタップ |

### 状態の流れ

```
（未出勤）→ 出勤 → 勤務中 → 退勤 → （退勤済み）
                      ↓
                  休憩開始 → 休憩中 → 休憩終了 → 勤務中
```

- グループ（sunabaco / sofe）を選んで打刻してください
- コメントは任意で入力できます

## シフト申請（シフトタブ）

### 申請の手順

1. カレンダーで申請したい日をタップ
2. 右のパネルでテンプレートを選ぶか、時刻を直接指定する
3. 「申請する」をタップ
4. 管理者が確認・承認すると「確定済み」になる

### テンプレート一覧

| テンプレート | 時間 |
|-------------|------|
| sofe 通し   | 9:30 〜 17:30 |
| sofe 早番   | 9:30 〜 14:00 |
| sofe 遅番   | 13:00 〜 17:30 |
| sunabaco    | 17:00 〜 21:00 |

### カレンダーの色

| 色 | 意味 |
|----|------|
| 緑 | 確定シフト（自分） |
| 黄 | 申請中（自分） |
| 青 | 他メンバーの確定シフト |
| 紫 | 打刻あり |

### シフト申請の取り消し
- 申請中（未確定）のシフトは、日付をタップ → 「申請を取り消す」で削除できる
- 確定済みのシフトは取り消しできない（管理者に連絡）

### 打刻修正申請（シフト画面から）
日付をタップすると打刻実績の横に「＋ 修正申請」ボタンが表示されます。

1. 「＋ 修正申請」をタップ
2. 種別（出勤 / 退勤）と時刻を選ぶ
3. 理由を入力（任意）
4. 「申請する」をタップ
5. 管理者が承認すると実績に反映される

## 管理者向け

管理者（admin）でログインすると「管理者パネル」タブが追加されます。

### メンバー管理
- ロール変更：メンバー / リーダー / 管理者 を設定できる
- パスワードリセット：初期パスワード `sofe0333` に戻す（次回ログイン時に変更を促す）
- メンバー削除：アカウントを削除する（adminは削除不可）

### シフト承認
- 申請されたシフトを「確定」または「拒否」する

### 打刻修正申請の承認
- メンバーからの修正申請を「承認」または「却下」する
- 承認すると打刻実績に反映される（修正済マーク付き）

### 打刻実績ログ
- メンバーごとの打刻履歴を直近30日分確認できる

## データ保存・バックアップ

全データは `data/db.json` に保存されます。  
バックアップはこのファイルをコピーするだけです。

---

## 複数端末で使う（スマホ・他のPC）

サーバーを起動しているPCと同じWi-Fiに接続していれば、スマホや他のPCからもアクセスできます。

1. サーバーPCのIPアドレスを確認する
   ```
   ipconfig
   ```
   → `IPv4 アドレス` の値（例: `192.168.1.10`）

2. スマホのブラウザで `http://192.168.1.10:3000` を開く
